# Ozri — V10 Horror Pass

## Запуск
Windows: `START_WINDOWS.bat`
Linux/macOS: `./start_linux_mac.sh`

Если запускаешь вручную, подними простой HTTP-сервер в папке проекта и открой `index.html`.

## Что изменено в V10
- Отец возвращён к более раннему, простому визуальному виду, но теперь правильно лежит вдоль кровати и лицом вверх.
- Исправлена точка камеры во время разговоров с отцом.
- Финальный мальчик развернут в противоположную сторону, чтобы в сцене он был ориентирован к Озри, а не к камере.
- Вода в сцене с матерью заменена на чистый полупрозрачный материал без странной текстуры.
- После поднятия последнего пера добавлен отдельный playable red-corridor maze: настоящий FPS-лабиринт с выходом, далеким щебетанием Озри и отдельным сердцебиением.
- После выхода из лабиринта сюжет возвращается к поиску Озри в доме.
- Добавлены более заметные heartbeat-слои при приближении к матери, отцу, в лабиринте и перед финальной находкой.
- Финальный плач переработан в более приглушённый, тяжёлый и тревожный звук; анимация рыданий стала медленнее и менее карикатурной.
- Добавлены новые локальные аудиофайлы `maze_chirps.wav`, `dread_heartbeat.wav`, `boy_sob_dark.wav`.

## Управление
- WASD — движение
- Мышь — камера
- Shift — бег
- E — взаимодействие
- I — инвентарь
- F — фонарь

Есть мобильное управление: левый стик, свайп справа для камеры, кнопки взаимодействия/инвентаря/фонаря.


## V10 hotfix
- Исправлена точка возврата из красного лабиринта: прежняя точка попадала в коллизию аптечного шкафа.
- Добавлен автоматический поиск ближайшей свободной позиции при телепортации назад.
- При возврате сбрасывается зажатое движение/стик, чтобы игрок не въезжал обратно в препятствие в первый кадр.

## V10 Mobile Hosting build
This folder is ready for static hosting. Upload its CONTENTS to a web root.
- Netlify Drop: drag the whole folder into Netlify Drop.
- GitHub Pages: put `index.html` in the repository root and enable Pages from `main / (root)`.
- Mobile: landscape orientation is recommended. Tap the Start button once to unlock browser audio.
