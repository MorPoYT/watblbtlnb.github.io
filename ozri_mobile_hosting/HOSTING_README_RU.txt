OZRI — ЗАПУСК НА ТЕЛЕФОНЕ ЧЕРЕЗ ИНТЕРНЕТ

САМЫЙ БЫСТРЫЙ СПОСОБ — NETLIFY DROP
1. Распакуй этот ZIP.
2. Открой https://app.netlify.com/drop
3. Перетащи ПАПКУ ozri_mobile_hosting целиком в окно браузера.
4. Netlify выдаст ссылку вида https://имя-сайта.netlify.app
5. Открой эту ссылку на телефоне.

GITHUB PAGES
1. Создай новый публичный репозиторий на GitHub.
2. Загрузи ВСЕ файлы из папки ozri_mobile_hosting В КОРЕНЬ репозитория.
   Важно: index.html должен лежать прямо в корне репозитория, а не во второй вложенной папке.
3. Открой Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, Folder: /(root), затем Save.
6. GitHub даст адрес примерно:
   https://ТВОЙ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/
7. Открой его на телефоне.

ВАЖНО
- Интернет нужен: Three.js пока загружается с CDN.
- На телефоне лучше повернуть экран горизонтально.
- При первом запуске обязательно нажми кнопку ПРОСНУТЬСЯ: это разрешает браузеру включить звук.
- Если iPhone молчит, проверь беззвучный режим и громкость мультимедиа.
